# Фото для портфолио — без AI-лица

Генераторы (ChatGPT, Gemini, Midjourney) **не умеют** сделать «то же лицо, но лучше» без пластика и артефактов. Звёздочка в углу = сгенерировано заново.

## Что работает (15 минут)

1. Возьмите **исходное селфи** (серый свитер, без фильтров).
2. [remove.bg](https://www.remove.bg) — только фон → светло-серый или белый.
3. **Snapseed** или **Lightroom Mobile**:
   - Яркость +5…10
   - Тени лица +10
   - Резкость только глаза (Structure 10–15)
   - **Не** Smooth / Beauty / Portrait AI
4. Кадр: грудь и выше, лицо по центру.

## Новое фото за 2 минуты (лучше любого AI)

- Встать к **окну** (свет на лицо).
- Телефон на уровне глаз.
- Лёгкая **настоящая** улыбка.
- Фон: однотонная стена.
- 10 кадров → выбрать одно.
